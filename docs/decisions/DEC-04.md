# DEC-04: One dense map, many contracts

## Context

The reference game structures depth as one perch map replayed through many contracts and challenge tiers. The person chose 'One map, many contracts'.

## Decision

The Gumdrop Jubilee is the level. Depth comes from contracts (target sets and conditions), side jobs, challenges and mastery layered onto the same diorama, not from new maps. Contracts are data the sim loads.

## Why

Replayability comes from learning one place deeply, and all the art and performance effort goes into a single diorama that has to run well on phones.

## Alternatives rejected

Several distinct maps, which multiplies art and performance cost before the core is proven. Deciding later, which leaves the contract format unshaped.

## Consequences

The contract and schedule format must be data-driven from the start. New maps are out of scope until the north star changes.
