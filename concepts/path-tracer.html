Keys

Pen: click = corner point · click-drag = smooth point · click first point = close · Esc = stop drawing
Any tool: hover a line (it turns yellow) and drag to bend it · Edit: drag point / handle · Alt-drag handle = break symmetry · double-click point = smooth ↔ corner · Shift-click segment = insert point · Del = delete point
View: wheel = zoom · Space-drag or middle-drag = pan · F = fit · Ctrl+Z / Ctrl+Shift+Z undo/redo
Arrow keys nudge the selected point (Shift = 10px).
